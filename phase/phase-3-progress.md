# Phase 3 — Progress

## Objective

Answer:

> "Am I progressing?"

Use only data already stored by previous phases.

Do not change the data model unless absolutely necessary.

---

# Body Progress

Display:

## Weight

Trend chart:

```text
7D
30D
90D
```

Use a trend line rather than emphasizing daily fluctuations.

---

## Waist

Same time ranges.

---

# Strength Progress

For exercises with enough history:

Display:

```text
Exercise
Best weight
Best reps
Recent performance
```

Example:

```text
Bench Press

Week 1
60kg × 8

Week 2
60kg × 9

Week 3
62.5kg × 8
```

---

# Cardio Progress

If cardio sessions exist:

Display:

```text
Distance
Duration
Pace
```

Focus on simple trends.

---

# Workout Consistency

Display:

```text
Completed sessions
Planned sessions
Adherence %
```

---

# Weekly Summary

Show:

```text
Workout
Body
Nutrition
Performance
```

Keep it concise.

---

# Acceptance Criteria

User can open Progress and understand:

* Whether weight is changing.
* Whether waist is changing.
* Whether strength is improving.
* Whether cardio is improving.
* Whether workouts are consistent.

No manual calculation should be required.

---

# Non-Goals

Do NOT implement:

* Adaptive workout changes
* Nutrition adjustments
* AI
* Fitness scores
* Complex analytics
* Predictions
